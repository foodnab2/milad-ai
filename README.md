## 🌟 معرفی پروژه (Overview)

**MILAD AI** یک وب‌اپلیکیشن پیشرفته (Progressive Web App) با پشتیبانی کامل از زبان فارسی (RTL) است که امکان مکالمه متنی، ارسال فایل و **مکالمه صوتی زنده (Real-Time Live Voice)** را با کمترین تأخیر فراهم می‌کند.

### ✨ قابلیت‌های کلیدی (Key Features)
* 🎙️ **مکالمه زنده دوطرفه (Live Voice Streaming):** ارتباط صوتی بلادرنگ از طریق WebSocket و پردازش صوتی PCM.
* 🗣️ **پشتیبانی از صدای طبیعی (TTS):** امکان انتخاب صدای سخنگوی مردانه و زنانه به همراه خوانش خودکار پاسخ‌ها.
* 📱 **طراحی واکنش‌گرا و PWA:** قابل نصب روی iOS و Android با منوی کشویی موبایل.
* 🗂️ **مدیریت تاریخچه گفتگوها:** ذخیره، بازیابی و حذف گفتگوها در حافظه مرورگر به همراه پشتیبانی از پیوست فایل و تصویر.
* 🔒 **معماری امن سمت سرور:** مدیریت نشست‌ها در بک‌اند بدون افشای API Key در سمت کاربر.

## 🚀 راه‌اندازی سریع (Quick Start)

```bash
git clone [https://github.com/](https://github.com/)foodnab2/milad-ai.git
cd milad-ai
npm install
cp .env.example .env
node server.mjs
```

---

## 🛠️ تکنولوژی‌ها (Tech Stack)
* **Backend:** Node.js (`server.mjs`), WebSockets (`ws`), Native Fetch/Streams
* **Frontend:** Vanilla JavaScript (ES6+), Modern CSS3 (Glassmorphism Dark UI), Web Audio API
* **AI Integration:** Google Gemini Multimodal & Live API
